# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to the maintainers. All security vulnerabilities will be promptly addressed.

**Please do NOT report security vulnerabilities through public GitHub issues.**

## Disclosure Policy

When the maintainers receive a security bug report, they will:

1. Confirm the problem and determine the affected versions
2. Audit code to find any potential similar problems
3. Prepare fixes for release
4. Publish a security advisory

## Security Best Practices

When using this project:

- Never run attacks against production systems
- Always use isolated sandbox environments
- Rotate API keys regularly
- Monitor API usage for unauthorized access
- Use environment variables for secrets (never commit .env files)
- Enable Docker resource limits when running in containers

## Scope

This security policy applies to the latest release of Adversarial Agent Evaluation.

## Acknowledgments

We appreciate the efforts of security researchers who responsibly disclose vulnerabilities.
